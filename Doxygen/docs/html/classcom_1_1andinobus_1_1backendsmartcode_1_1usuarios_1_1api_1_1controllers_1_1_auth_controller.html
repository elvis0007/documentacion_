Descripción detallada

Controlador REST para manejo de autenticación y autorización.

Proporciona endpoints para login, registro, consulta de perfil y logout. Solo está activo en el perfil 'dev' que utiliza base de datos.

Endpoints disponibles:

  • POST /api/auth/login - Iniciar sesión
  • POST /api/auth/register - Registrar nuevo usuario
  • GET /api/users/me - Obtener datos del usuario actual
  • POST /api/auth/logout - Cerrar sesión

AuthDtos.AuthResponse com.andinobus.backendsmartcode.usuarios.api.controllers.AuthController.login ( @Valid @RequestBody AuthDtos.LoginRequest req)

Endpoint para iniciar sesión en el sistema.

Valida las credenciales del usuario y genera un token JWT válido por 30 días. El token debe ser incluido en futuras peticiones como Bearer token.

Parámetros
reqDatos de login validados con email y contraseña
Devuelve
Respuesta con token JWT y datos básicos del usuario
Excepciones
RuntimeExceptionSi las credenciales son inválidas
jakarta.validation.ConstraintViolationExceptionSi los datos no son válidos
Nota
Endpoint público, no requiere autenticación previa

AuthDtos.AuthResponse com.andinobus.backendsmartcode.usuarios.api.controllers.AuthController.register ( @Valid @RequestBody AuthDtos.RegisterRequest req)

Endpoint para registrar un nuevo usuario en el sistema.

Crea una nueva cuenta de usuario con rol CLIENTE por defecto. Valida que el email no esté en uso y encripta la contraseña.

Parámetros
reqDatos de registro con email, contraseña y datos personales opcionales
Devuelve
Respuesta con token JWT y datos del usuario recién creado
Excepciones
RuntimeExceptionSi el email ya está registrado
jakarta.validation.ConstraintViolationExceptionSi los datos no son válidos
Nota
Endpoint público, crea usuarios con rol CLIENTE automáticamente
Retorna status HTTP 201 Created en caso de éxito
