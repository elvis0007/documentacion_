Descripción detallada

Controlador REST para gestión de frecuencias de rutas.

Administra las frecuencias de viajes que definen horarios regulares entre ciudades. Las frecuencias son plantillas que se usan para generar viajes específicos con fechas y disponibilidad.

Operaciones CRUD disponibles:

  • POST /api/cooperativas/{id}/frecuencias - Crear nueva frecuencia
  • GET /api/cooperativas/{id}/frecuencias - Listar frecuencias por cooperativa
  • GET /api/frecuencias/{id} - Obtener frecuencia específica
  • PUT /api/frecuencias/{id} - Actualizar frecuencia
  • DELETE /api/frecuencias/{id} - Eliminación lógica de frecuencia

Casos de uso principales:

  • Cooperativas definen horarios regulares de viajes
  • Administración de rutas y horarios por origen-destino
  • Base para generar viajes específicos con disponibilidad
  • Configuración de precios y tipos de servicio
