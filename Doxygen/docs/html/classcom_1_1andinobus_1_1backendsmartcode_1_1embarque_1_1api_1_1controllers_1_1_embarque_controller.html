Descripción detallada

Controlador REST para gestión del proceso de embarque de pasajeros.

Maneja la validación y escaneo de boletos en el momento del embarque. Registra accesos, previene uso duplicado de boletos y mantiene log de auditoría de todas las operaciones de embarque.

Funcionalidades principales:

  • Escaneo y validación de códigos QR de boletos
  • Prevención de uso duplicado de boletos
  • Registro de log de auditoría en base de datos
  • Validación de formato y estado de boletos

Flujo típico de embarque:

  1. Oficinista escanea código QR del boleto
  2. Sistema valida formato y estado del código
  3. Si es válido y no usado, permite embarque
  4. Marca boleto como "usado" para prevenir reutilización
  5. Registra evento en log de auditoría

EmbarqueDtos.ScanResponse com.andinobus.backendsmartcode.embarque.api.controllers.EmbarqueController.scan ( @RequestBody EmbarqueDtos.ScanRequest req)

Escanear y validar código QR de boleto para embarque.

Valida formato del código, verifica que no haya sido usado previamente y registra el acceso en el sistema. Implementa lógica de negocio para prevenir embarques duplicados y mantener auditoría de accesos.

Parámetros
reqSolicitud con código QR escaneado del boleto
Devuelve
Resultado de validación con estado y mensaje explicativo
Excepciones
IllegalArgumentExceptionSi el código está vacío o es nulo

Estados posibles de respuesta:

  • "usado" + válido=true: Embarque exitoso (primera vez)
  • "usado" + válido=true: Boleto ya fue usado previamente
  • "invalido" + válido=false: Formato de código incorrecto
Nota
Acepta tanto "/embarque/scan" como "/embarcque/scan" (typo legacy)
Códigos válidos deben tener al menos 6 caracteres
Una vez escaneado exitosamente, el boleto no puede reutilizarse
Registra todas las operaciones en log de auditoría
