Descripción detallada

Servicio de lógica de negocio para autenticación y autorización.

Implementa el sistema completo de autenticación basado en tokens, incluyendo registro de usuarios, login, gestión de sesiones y validación de credenciales. Maneja tokens con expiración automática.

Funcionalidades principales:

  • Registro de nuevos usuarios con validación de email único
  • Autenticación con email/contraseña y generación de tokens
  • Gestión de sesiones con tokens de 30 días de duración
  • Validación de tokens y obtención de información de usuario
  • Limpieza automática de tokens expirados
  • Logout seguro con invalidación de tokens

Seguridad implementada:

  • Contraseñas hasheadas con BCrypt
  • Tokens únicos generados con UUID
  • Validación de usuarios activos
  • Control de expiración de tokens
  • Prevención de emails duplicados

Autenticar usuario existente.

Valida credenciales (email/contraseña), verifica estado activo y genera nuevo token de sesión. Implementa validaciones de seguridad para prevenir accesos no autorizados.

Parámetros
reqCredenciales del usuario (email y contraseña)
Devuelve
Respuesta con token y datos del usuario autenticado
Excepciones
RuntimeExceptionSi las credenciales son incorrectas o el usuario está inactivo

Proceso de autenticación:

  1. Buscar usuario por email
  2. Validar contraseña con hash almacenado
  3. Verificar que el usuario esté activo
  4. Generar nuevo token de sesión
Nota
Mensaje genérico "Credenciales incorrectas" por seguridad
No revela si el email existe o no
Operación transaccional completa

AuthDtos.AuthResponse com.andinobus.backendsmartcode.usuarios.application.services.AuthService.register ( AuthDtos.RegisterRequest req)

Registrar nuevo usuario en el sistema.

Implementa el proceso completo de registro incluyendo validación de email único, hashing de contraseña, creación de usuario y generación automática de token de sesión.

Parámetros
reqDatos del usuario a registrar
Devuelve
Respuesta con token y datos del usuario creado
Excepciones
RuntimeExceptionSi el email ya está registrado

Proceso de registro:

  1. Validar que el email no exista
  2. Crear usuario con contraseña hasheada
  3. Asignar rol "CLIENTE" por defecto
  4. Activar usuario automáticamente
  5. Generar token de sesión válido por 30 días
Nota
Operación transaccional completa
Contraseña se hashea con BCrypt automáticamente
Usuario queda autenticado inmediatamente
