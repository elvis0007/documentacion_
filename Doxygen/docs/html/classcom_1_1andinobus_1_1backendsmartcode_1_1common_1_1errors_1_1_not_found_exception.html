Descripción detallada

Excepción específica para recursos no encontrados.

RuntimeException personalizada que indica que un recurso solicitado no existe en el sistema. Es capturada por GlobalExceptionHandler para retornar HTTP 404.

Casos de uso típicos:

  • Usuario no encontrado por ID
  • Cooperativa no existe para asociar bus
  • Frecuencia no encontrada para crear parada
  • Reserva no existe para proceso de pago
  • Cualquier entidad no encontrada en repositorio
