Descripción detallada

Servicio de lógica de negocio para gestión de buses.

Implementa las operaciones de negocio para administrar la flota de buses de las cooperativas, incluyendo validaciones, persistencia y transformaciones de datos. Maneja la relación bus-cooperativa.

Responsabilidades principales:

  • Validar datos técnicos de buses antes de persistir
  • Verificar existencia de cooperativas para asociación
  • Gestionar estado activo/inactivo de buses
  • Proporcionar consultas paginadas por cooperativa
  • Transformar entidades a DTOs para API

Reglas de negocio implementadas:

  • Bus debe pertenecer obligatoriamente a una cooperativa
  • Placa debe ser única en el sistema
  • Buses se crean activos por defecto
  • Solo se consultan buses activos
