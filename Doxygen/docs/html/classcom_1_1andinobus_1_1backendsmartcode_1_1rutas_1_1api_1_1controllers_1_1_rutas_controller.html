Descripción detallada

Controlador REST para gestión de rutas y viajes disponibles.

Proporciona endpoints para buscar rutas de transporte, consultar viajes programados y verificar disponibilidad de asientos. Maneja la lógica de búsqueda por origen/destino/fecha y la consulta de información de buses asignados.

Endpoints disponibles:

  • GET /api/rutas/buscar - Búsqueda de rutas con filtros
  • GET /api/viajes - Viajes programados por fecha
  • GET /api/viajes/{id}/disponibilidad - Disponibilidad de asientos
  • GET /api/viajes/{id}/bus - Información del bus asignado

Flujo típico de búsqueda:

  1. Cliente busca rutas por origen/destino/fecha
  2. Cliente selecciona una frecuencia específica
  3. Sistema muestra viajes disponibles para esa fecha
  4. Cliente consulta disponibilidad de asientos
  5. Cliente puede proceder a reservar
