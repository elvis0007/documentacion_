Descripción detallada

Controlador REST para gestión del proceso de ventas de boletos.

Maneja el ciclo completo de venta: reservas, pagos y emisión de boletos. Implementa lógica de negocio para reservas con expiración automática y múltiples métodos de pago.

Endpoints disponibles:

  • POST /api/reservas - Crear reserva con expiración 15 min
  • GET /api/reservas/{id} - Consultar estado de reserva
  • POST /api/pagos/transferencia - Pago por transferencia bancaria
  • POST /api/pagos/paypal/webhook - Webhook de PayPal
  • POST /api/boletos/emitir - Emitir boleto para reserva pagada
  • GET /api/boletos/{codigo} - Consultar boleto por código

Flujo típico:

  1. Cliente crea reserva → estado "pendiente"
  2. Cliente realiza pago → estado "pagado"
  3. Cliente emite boleto → genera código QR
  4. Oficinista escanea para embarque
