Descripción detallada

Controlador REST para gestión de flota de buses.

Proporciona endpoints para administrar la flota de buses de cada cooperativa, incluyendo registro, consulta y listado. Los buses están organizados jerárquicamente bajo cooperativas.

Operaciones disponibles:

  • POST /api/cooperativas/{id}/buses - Registrar nuevo bus
  • GET /api/cooperativas/{id}/buses - Listar buses de cooperativa
  • GET /api/buses/{id} - Obtener información específica de bus

Casos de uso principales:

  • Administradores registran nuevos buses para cooperativas
  • Consulta de flota disponible por cooperativa
  • Verificación de especificaciones técnicas de vehículos
  • Asignación de buses a rutas y horarios
