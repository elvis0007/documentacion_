🚀 Inicio Rápido

Prerrequisitos

  • Java 17+
  • PostgreSQL 13+ (opcional para modo dev)
  • Maven 3.8+

Instalación

# Clonar el repositorio
git clone https://github.com/AlexiP18/backend-andinobus.git
cd backend-andinobus
# Configurar base de datos (opcional)
cp src/main/resources/application-dev.properties.example src/main/resources/application-dev.properties
# Editar application-dev.properties con tus credenciales
# Compilar
mvn clean package
# Ejecutar
mvn spring-boot:run

O en Windows:

run-dev.bat

Modo Demo (Sin Base de Datos)

El backend funciona sin configurar PostgreSQL usando stubs en memoria para desarrollo rápido.

mvn spring-boot:run -Dspring-boot.run.profiles=default

Modo Desarrollo (Con Base de Datos)

mvn spring-boot:run -Dspring-boot.run.profiles=dev

🏗️ Arquitectura

Tecnologías

  • Spring Boot 3.5.7 - Framework principal
  • PostgreSQL - Base de datos
  • Flyway - Migraciones de BD
  • Lombok - Reducción de boilerplate
  • Jakarta Validation - Validación de datos
  • Spring Security Crypto - Cifrado de contraseñas

Estructura Modular

com.andinobus.backendsmartcode/
├── catalogos/ # Cooperativas, buses, frecuencias
├── usuarios/ # Autenticación y usuarios
├── ventas/ # Reservas, pagos, boletos
├── rutas/ # Búsqueda de rutas y viajes
├── embarque/ # Validación de boletos
├── operacion/ # Generación de hojas de ruta
├── planificacion/ # Planificación de viajes
├── configuracion/ # Configuración del sistema
└── common/ # Utilidades compartidas

Cada módulo sigue arquitectura por capas:

  • api/ - Controladores REST y DTOs
  • application/ - Servicios de aplicación
  • domain/ - Entidades y lógica de negocio
  • infrastructure/ - Implementaciones técnicas

🔐 Roles y Seguridad

Rol Descripción
CLIENTE Usuario final (app móvil)

COOPERATIVA Administrador de cooperativa
ADMIN Super administrador

📦 Módulos Principales

1. Autenticación (/auth/*)

  • Login con email/password
  • Registro de usuarios
  • Gestión de tokens JWT
  • Perfil de usuario

2. Rutas y Viajes (/rutas/*, /viajes/*)

  • Búsqueda de rutas por origen/destino
  • Consulta de disponibilidad
  • Información de buses
  • Listado de viajes por fecha

3. Ventas (/reservas/*, /pagos/*, /boletos/*)

  • Creación de reservas (expiran en 15 min)
  • Procesamiento de pagos (transferencia, PayPal)
  • Emisión de boletos con QR
  • Consulta de boletos

4. Embarque (/embarque/*)

  • Validación de boletos por código/QR
  • Registro de embarques
  • Control de boletos usados

5. Catálogos (Admin)

  • Gestión de cooperativas
  • Gestión de buses
  • Configuración de frecuencias
  • Definición de paradas

6. Operación (Admin)

  • Generación automática de viajes
  • Hojas de ruta
  • Asignación de buses

🐛 Troubleshooting

Error de conexión a BD

Error: Cannot connect to database

Solución: Verifica PostgreSQL está corriendo o usa perfil default para modo demo

Puerto 8080 en uso

Error: Port 8080 is already in use

Solución: Cambia el puerto en application.properties:

server.port=8081

Flyway migration failed

Error: Flyway migration failed

Solución: Limpia la BD o ajusta spring.flyway.baseline-on-migrate=true
